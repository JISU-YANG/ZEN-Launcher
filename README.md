# ZEN Launcher: 빠른 실행을 위한 개인 런처

ZEN Launcher는 자주 사용하는 프로그램, 웹사이트, 폴더, 검색, 위젯 기능을 하나의 화면에서 빠르게 실행할 수 있도록 만든 Electron 기반 런처입니다.

![ZEN Launcher Thumbnail](./doc/thumbnail-01.png)

[프로젝트 회고 보기](https://jisulog.com/docs/essay/project-review/2023-np-launcher)

## 시작하기

### 설치

GitHub Releases에서 Windows 설치 파일을 받아 실행합니다.

- 64비트: `zen-launcher-<version>-setup-x64.exe`
- 32비트: `zen-launcher-<version>-setup-ia32.exe`

설치 경로는 바꿀 수 있고, 기본값은 사용자 폴더입니다. 관리자 권한 없이 설치됩니다. 이미 설치한 앱은 실행할 때 GitHub Releases를 확인하고, 새 버전이 있으면 받은 뒤 재시작으로 설치합니다.

이전에 쓰던 portable 실행 파일에는 자동 업데이트가 없습니다. 설치 파일을 한 번 설치하면 이후 버전부터 자동 업데이트가 이어집니다.

### 개발 실행

```bash
npm install
npm start
```

## 주요 기능

- 로컬 프로그램 실행
- 웹사이트 바로가기 실행
- 폴더 바로 열기
- 검색 엔진 프리픽스 검색
- 날씨 위젯
- Quick Tools 위젯
- 예약 종료 위젯
- Windows 설정 및 기본 도구 바로가기
- 라이트/다크 테마와 런처 투명도
- 시스템 트레이와 Windows 시작 시 실행
- GitHub Releases 기반 자동 업데이트

## 사용 기술

- JavaScript
- HTML/CSS
- Electron
- electron-store
- electron-shutdown-command
- electron-updater

## 설치 파일 만들기

로컬에서 설치 파일만 만들 때는 아래를 실행합니다. 64비트 메타데이터는 `latest.yml`, 32비트 메타데이터는 `latest-ia32.yml`이며, 앱에 들어가는 업데이트 주소는 GitHub Releases입니다.

```bash
npm run build:win64
npm run build:win32
```

`v`와 `package.json`의 `version`을 맞춘 태그(예: `v2.3.6`)를 푸시하면 GitHub Actions가 32비트/64비트 설치 파일과 업데이트 메타데이터를 릴리스에 올립니다.

## 릴리스 노트

### v2.3.8 (2026-11-09)

- 아이콘을 편집할 때 추천에서 계산기, 시계, 메모장, 캡처도구, 그림판, 화상 키보드를 고를 수 있습니다.
- 폴더 추천에는 바탕화면, 다운로드, 스크린샷, 휴지통, 카카오톡 받은 파일이 있습니다.
- 갤러리 추천에는 MapleStory, Sudden Attack, League of Legends, VALORANT, BATTLEGROUNDS, Mabinogi가 있습니다. MapleStory, Sudden Attack, Mabinogi는 넥슨 플러그로, League of Legends와 VALORANT는 Riot Client로, BATTLEGROUNDS는 Steam으로 실행합니다. 포스터는 앱에 들어 있습니다.
- 갤러리 여섯 번째 칸도 추가할 수 있습니다.

### v2.3.7 (2026-11-09)

- 하단에 시작프로그램, 프로그램 추가/제거, 컴퓨터 정보를 넣었습니다. 순서는 화면, 소리, 마우스, 키보드, 시작프로그램, 프로그램 추가/제거, 컴퓨터 정보입니다.
- 아이콘은 Font Awesome입니다. 화면은 모니터, 소리는 헤드폰, 시작프로그램은 로켓, 프로그램 추가/제거는 더하기와 빼기, 컴퓨터 정보는 본체입니다.
- 다른 앱이 화면을 가득 덮으면 Ctrl+Space 등록을 풀어 그 앱이 단축키를 받습니다. 이미 삼킨 키는 다시 만들지 않습니다.

### v2.3.6 (2026-11-06)

- 환경설정을 왼쪽 2열 계층 탐색으로 바꿨습니다. 항목, 모양, 동작, 데이터로 나뉘고, 단축키·전체 화면·시작이 따로 있습니다.
- 자동으로 잡힌 해상도와 위치를 보여 주고, 화면 배치를 픽셀 단위로 보정할 수 있습니다.
- 설정 JSON을 내보내고 불러올 수 있습니다.
- 갤러리·아이콘 편집에서 이미지를 올리고, 링크·프로그램·추천으로 고를 수 있습니다.
- 프로그램 탐색은 시스템 항목과 이미 추가된 항목을 기본적으로 숨기고, 숨긴 프로그램을 볼 수 있습니다.
- 저장하지 않고 닫기, 초기화, 삭제, 실행 실패, 업데이트 안내는 시스템 창 대신 런처 안 대화상자로 엽니다.
- 설정 시트는 런처와 같은 높이를 유지하고, 항목 편집과 프로그램 탐색에서만 커집니다.

### v2.3.5 (2026-11-06)

- 화면 글꼴을 Google Fonts의 Noto Sans KR 대신 앱에 포함한 Pretendard로 바꿨습니다. 인터넷이 없어도 글꼴 굵기가 그대로 적용됩니다.
- 아이콘 이미지 모서리를 런처 카드와 같은 12px 라운드로 맞췄습니다.
- 날씨 온도의 크기, 굵기, 자간을 본문과 맞춰 정리했습니다.

### v2.3.4 (2026-11-06)

- 갤러리 세로를 32px 줄이고, 아이콘 바를 52px에서 84px로 키웠습니다. 아이콘 그림은 26px입니다. 런처 전체 높이는 그대로입니다.

### v2.3.3 (2026-11-06)

- 갤러리와 아이콘에 넣은 이미지는 기본적으로 흑백입니다. 마우스를 올리면 원래 색이 보이고, 테마 설정의 “평소에는 흑백으로 보기”로 끌 수 있습니다.
- 갤러리 이미지는 칸 안쪽에 12px 여백을 두고 들어갑니다. 칸의 바깥 크기는 그대로입니다.

### v2.3.2 (2026-11-06)

- 갤러리와 아이콘은 개수가 적어도 최대 칸을 유지해서 남은 항목이 늘어나지 않습니다. 직접 넣은 아이콘 이미지는 원래 색을 유지합니다.
- 런처 바탕을 검정 대신 어두운 회색으로 올리고, 글자와 아이콘은 중요할수록 밝게 맞췄습니다. 검색 안내, 폴더 아이콘, 온도, 강수량, 하단 버튼, 설정 아이콘은 이름보다 한 단계 어둡습니다.
- 사이드바 하단 이름은 ZEN Launcher로 띄어 씁니다.

### v2.3.1 (2026-11-06)

- 런처를 고른 여백으로 다시 배치했습니다. 검색, 폴더, 이름, 설정은 사이드바에 있고 하단 바는 본문 아래에서 끝납니다.
- 갤러리 이름은 마우스를 올렸을 때만 올라옵니다. 폴더에는 아이콘이 붙고, 빈 칸은 평소에 보이지 않다가 마우스를 올리면 테두리와 +가 나타납니다.

### v2.3.0 (2026-11-05)

- 아이콘 줄은 처음 실행할 때 계산기, 시계, 메모장, 캡처도구, 그림판, 화상 키보드로 채워집니다. 이후에는 빈 칸부터 바꾸고, 이미 있는 항목은 덮어쓰지 않습니다.
- 푸터 왼쪽에는 종료, 재시작, 예약, 볼륨이 있고, 오른쪽에는 화면, 마우스, 키보드, 소리와 런처 설정이 있습니다. 제작자 이름은 설정 화면으로 옮겼습니다.
- 창 크기는 작업 영역과 화면 배율에 맞춰 바닥 중앙에 붙습니다. 확장 시트는 열림, 닫힘, 같은 높이의 내용 전환, 높이 변경을 따로 움직입니다.

### v2.2.1 (2026-11-04)

- 실행 중에는 작업 표시줄 대신 시스템 트레이에 표시됩니다. 트레이 아이콘을 우클릭하면 현재 버전과 업데이트 확인·설치 메뉴가 나옵니다.

- 환경설정에 단축키 탭을 추가했습니다. 다른 앱이 전체 화면일 때 Ctrl+Space를 그 앱에 넘기는 옵션은 기본 꺼짐입니다.
