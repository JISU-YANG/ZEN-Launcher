# ZEN Launcher 컴포넌트 디자인 가이드

화면 문구는 한글이다. Google처럼 제품 이름만 원문을 둔다. 새 화면이 다른 모서리, 떠오르는 호버, 그림자, 영문 상태 알약을 추가하면 넣지 않는다. 숫자는 `index.html`의 `:root` 토큰과 같은 이름을 쓴다.

## 토큰

| 토큰 | 값 | 쓰는 곳 |
| --- | --- | --- |
| `--control-h` | 32px | ActionButton |
| `--control-h-sm` | 28px | IconButton |
| `--radius-control` | 8px | 버튼, 추가 슬롯 |
| `--icon-size` | 16px | 푸터와 명령 막대 아이콘 |
| `--hover-fill` | 흰 8% / 라이트에선 검 6% | 호버 배경 |
| `--press-fill` | 흰 12% / 라이트에선 검 10% | 눌림 배경 |
| `--focus-ring` | 2px | 키보드 포커스 |
| `--hairline` | 본문색 12% | 구분선, 시트 가장자리 |
| `--dock-height` | 420px, 작업 영역이 더 좁으면 줄어듦 | 닫힌 런처 높이 |
| `--layout-scale` | `min(1, 창 너비 / 1200)` | 타일 크기 |
| `--sheet-duration` | 동작별 | 시트 높이 |

호버는 배경만 바뀐다. 이동, 확대, 그림자는 쓰지 않는다.

## IconButton

클래스 `zen-icon-button`.

- 쓰는 곳: 종료, 재시작, 예약, 볼륨 -, 볼륨 +, 음소거, 화면, 마우스, 키보드, 소리, 런처.
- 쓰지 않는 곳: 저장처럼 문장이 본문인 동작, 갤러리 포스터.
- 크기: 높이 `--control-h-sm`, 아이콘 `--icon-size`, 패딩 좌우 8px, 짧은 한글 라벨.
- 상태: 기본은 투명. 호버와 선택(`aria-expanded="true"`)은 `--hover-fill`. 눌림은 `--press-fill`.
- 모션: 없음.
- 배치: 왼쪽은 누르면 바로 상태가 바뀌는 버튼. 오른쪽은 Windows 설정으로 나가는 버튼. 런처 설정은 오른쪽 맨 끝, 구분선 하나 뒤.

## ActionButton

클래스 `setting-action-button`. 강조는 `primary-button`, 위험은 `danger-button`.

- 쓰는 곳: 저장, 닫기, 초기화.
- 크기: 높이 `--control-h`, 모서리 `--radius-control`.
- 상태: 기본은 약한 면, 강조는 밝은 면과 어두운 글자, 위험은 글자색만 다르다.
- 모션: 없음.

## Row

클래스 `list-item`.

- 쓰는 곳: 폴더, 설정 목록.
- 호버: 밑줄 없이 `--hover-fill`.
- 빈 폴더 자리는 `zen-slot-add` 하나. 최대 개수까지 점선 칸을 채우지 않는다.

## Tile

클래스 `gallery-entry`, `icon-entry`.

- 쓰는 곳: 갤러리, 아이콘, 빠른 도구였던 기본 실행 항목.
- 크기: 갤러리는 96–132px, 아이콘은 한 줄에서 최대 104px. `--layout-scale`을 곱한다.
- 호버: 위치와 크기는 그대로 둔다.
- 아이콘 줄은 8칸이다. 처음 실행에서만 계산기, 시계, 메모장, 캡처도구, 그림판, 화상 키보드를 채우고 빈 칸 2개가 남는다. 이미 아이콘이 있으면 덮어쓰지 않는다. 추가는 빈 칸부터 하고, 8칸이 차면 그 칸을 직접 고쳐서 바꾼다.
- 갤러리는 채운 항목과 추가 버튼 하나만 보여 준다.

## 명령 막대

검색만 둔다. 폭은 440px, 모서리는 10px이다. 큰 그림자는 없다. 기본 테두리는 `--hairline`이고, 입력이 포커스일 때만 RGB 테두리가 흐른다.

## 도크 쉘

사선 줄무늬는 두지 않는다. 배경은 단색이다. 바깥 크기는 항목 수가 아니라 디스플레이가 바뀔 때만 다시 계산한다.

- 기준 폭 1200px. 작업 영역이 더 좁으면 좌우 16px을 남기고 줄인다.
- Electron이 주는 크기는 이미 배율이 반영된 논리 픽셀이다. `scaleFactor`를 다시 곱하지 않는다.
- 창 크기는 도크와 그 위 여백을 항상 포함한다. 시트가 닫혀도 창을 줄이지 않고, 보이는 영역만 도크 높이로 자른다.
- 도크 하단은 화면 높이의 20%만큼 화면 아래에서 띄운다. 작업 영역 밖으로 나가지 않는다.
- 상단 바는 한 줄이다. 왼쪽은 위치, 기온, 날씨 상태이고, 오른쪽은 체감·습도·강수 아이콘과 값이다.
- 상단 바와 하단 바는 같은 색이고, 런처 본문보다 어둡다.
- 갤러리 이미지 자리는 런처 표면보다 어둡다. 아이콘과 이름은 하나의 어두운 판 안에 둔다. 다크 모드에서 아이콘 그림은 흰색이다.
- `display-metrics-changed`에서 즉시 다시 앉힌다. 이 재배치는 애니메이션하지 않는다.

## 시트

클래스 `#editor`. 가장자리는 1px `--hairline`이다. RGB 띠와 10px 머리줄은 쓰지 않는다. `prefers-reduced-motion`이면 길이는 0이다.

세 대본만 있다.

| 대본 | 조건 | 길이 | 동작 |
| --- | --- | --- | --- |
| 처음 열림 `reveal` | 시트가 닫혀 있음 | 320ms | 창을 먼저 위로 늘리고, 높이가 도착한 뒤 내용을 보여 준다. |
| 닫힘 `conceal` | 시트를 닫음 | 내용 140ms, 시트 320ms | 내용은 이동 없이 사라진 뒤 시트가 접힌다. 접힌 다음 창을 도크 높이로 줄인다. |
| 같은 높이 `exchange` | 이미 열려 있고 높이가 같음 | 160ms | 시트는 멈춰 있고 내용만 페이드된다. |
| 커짐 `grow` | 이미 열려 있고 다음 높이가 큼 | 내용 140ms, 시트 300ms | 내용을 먼저 숨기고, 시트가 도착한 뒤 새 내용을 보여 준다. |
| 줄어듦 `shrink` | 이미 열려 있고 다음 높이가 작음 | 내용 140ms, 시트 200ms | 내용을 숨긴 뒤 시트를 줄이고, 도착 후 창을 맞춘다. |

높이는 역할로 고른다.

| fit | 높이 | 쓰는 패널 |
| --- | --- | --- |
| `peek` | 최대 112px | 한 줄 도구 |
| `panel` | 위쪽 여백의 42%, 220–그 여백 사이 | 예약 종료, 런처 설정 |
| `workspace` | 도크 위부터 작업 영역 상단까지 | 프로그램 탐색 |

다음 패널은 새 시간을 만들지 않고 이 fit 중 하나를 고른다.
